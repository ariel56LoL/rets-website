Important information about the RETS tester administration system.

Administrator password

The administrator password is supplied by the Cloudflare Secret ADMIN_PASSWORD. It is not stored in this HTML page.

Tester codes

Tester codes are generated by the server and stored in the RETS D1 database. Do not hard-code valid codes into client-side files.

Session

Administration requests use the authenticated session cookie created by the RETS Worker.

Data minimization

Store only the tester information required to operate the program.
